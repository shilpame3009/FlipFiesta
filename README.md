# Flip Fiesta

Flip Fiesta is a colorful memory matching game made with React, JavaScript, HTML, and CSS.

## Play

- Choose one of four colorful decks: Sweet Shop, Garden Party, Ocean Friends, or Pink Paradise.
- Choose a difficulty: Beginner (2 pairs), Easy (4), Medium (8), Tough (16), or Extreme (32).
- Flip two cards at a time and try to find every matching pair.
- Use Peek cards, Pause/Resume, and New round while you play.
- Earn a Sprinkle badge and try to beat your best moves.

Your chosen deck, difficulty, badge, and best scores are saved in this browser. They do not sync to another device.

## Run on your computer

1. Install Node.js.
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown in the terminal.

To make a production build, run `npm run build`.

## Technologies

React, JavaScript, HTML, and CSS. Vite runs the development server and creates the production build.
